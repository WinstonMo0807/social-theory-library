# 联动验收基线

## 单篇文献

发布一份测试 PDF 后：

- 搜索测试题名能够找到作品。
- 搜索测试学者能够找到人物和作品。
- 指定理论流派页面出现作品。
- 指定主题页面出现作品和学者。
- 学者页面馆藏作品出现该作品。
- 阅读器可以打开云端 PDF。
- 文档内搜索可以找到 PDF 文本。
- 全局全文结果可以跳转到具体 PDF 页并高亮。
- 引用使用最终书目数据和书库版本。
- 后台文献总数增加一。
- PDF 文件数量增加一。
- 上传记录、OCR 日志和发布记录可查看。
- 下架后前台、搜索、推荐和云端地址不再公开。
- 读者原有私人笔记仍可在个人中心查看。

## 批量入库

- 一个批次可以包含多个独立 PDF。
- 每个 PDF 使用独立请求上传，响应丢失后的重试不会建立重复记录。
- 某个 PDF 损坏时，其他 PDF 继续处理。
- 相同文件重复上传不会重复建立作品。
- 系统重启后未完成任务可以继续。
- 失败项目可以单独重试。
- 批次中每份文件拥有独立日志和公开结果。
- 多次重试不会增加重复统计或知识关系。

## PDF 替换

- 新文件处理完成前，旧文件继续在线阅读。
- 新文件的元数据识别不能覆盖已发布且锁定的书目信息。
- 新文件完成逐页文本、索引和云端同步后，才切换为当前版本。
- 旧阅读接口停止提供，新的阅读、下载和文档内搜索接口可用。
- 旧原件和规范文件继续保存在 NAS。
- 旧批注标记为待迁移，并保留在读者个人数据中。

## 权限

- 访客可以搜索、阅读、下载、复制和引用。
- 访客不能写入批注、收藏或进度。
- 读者只能查看自己的私人阅读数据。
- 编辑不能管理用户、云端密钥和备份。
- 管理员可以直接重置用户密码，但无法读取旧密码。
- 管理员不能从界面查看其他用户笔记正文。

## 云端阅读

- 公开前云端副本已存在且校验一致。
- 阅读和下载数据不经过 NAS。
- 签名地址过期后阅读器能够刷新。
- 下架后旧书库地址不能再签发云端地址。
- 达到预算阈值后停止新发布，但已经公开的文献仍可阅读。
