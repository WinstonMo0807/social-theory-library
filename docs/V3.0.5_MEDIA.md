# 媒体资产、封面与推荐图例发布

当前已接入媒体库、Work 封面与推荐图例。2026-09-12学者肖像的媒体选择、私有草稿预览与人工发布已完成本地浏览器验收。KnowledgeNode、ReadingPath 和完整旧图片迁入仍待完成，不能称整个媒体升级完成。

原图片保存在独立 MediaAsset，以 SHA-256 去重，保留来源、使用权、许可、署名、alt 和焦点。只接受实际内容、MIME 和后缀一致的 JPEG/PNG/WebP，限制 20 MB 与 2400 万像素。媒体默认不公开，后台文件接口需要原管理权限。

衍生图为独立 MediaRendition。书封保持比例，肖像和横幅支持焦点裁切；宽度档位 320/640/1280，不放大小图。相同参数复用，焦点变化保留旧结果。公开修订以 CatalogPublicationMedia 的真实保护 FK 引用具体衍生图，不能由常规删除误删已发布图像。小图 srcset 去重并保留主图。

Work.cover_rendition 是媒体封面选择，旧 cover 文件字段作为兼容读取路径保留。已发布作品选择媒体进入原 EditorialRevision，正式发布才捕获媒体说明、许可和精确 rendition ID。随后修改 MediaAsset 不会改变旧活动快照。旧 PDF 封面入口保留，并在人工选择 legacy 文件时清除媒体选择，避免双来源冲突。

衍生图同时保存当次选择的说明、来源、许可和署名。仅编辑这些资料也会产生新的版本 ID，管理员重新选择后才能进入书目草稿，发布前可核对文字差异。资料不会在准备和实际发布之间随源对象更新。后台完整页面预览使用已保存的编辑修订及私有图片 URL；公开页面仍只服务活动版本。Model.save 与 QuerySet.update 保护原件及衍生图的文件身份和已保存资料，不声称能阻止直接 SQL 或存储层覆写。

公开图片端点只接受当前活动快照登记的 rendition ID，不能借 UUID 读取其他私有媒体。书卡使用 srcset 选择适合尺寸，原件不进入公共响应。框架 Image 组件对开发机私网地址的防护保留；已由后端缩放的图片用原生 picture/img 直接由浏览器读取。

## 推荐图例

Work.recommendation_rendition 与 cover_rendition 分别记录选择。图例使用 hero 裁切和 320/640/1280 档位，实际宽度不超过原图。旧 Work.recommendation_image 路径保留兼容；旧文件不自动改写或迁入。

原推荐图例上传、重新生成和移除 HTTP 入口保留。新上传进入 MediaAsset，PDF 图例复用既有页面渲染后进入同一个媒体服务。已经发布的作品只建立 EditorialRevision，读取后台草稿预览不修改 canonical Work。移除只清除选择，不删除原件、旧衍生图或旧路径文件。没有独立图例时回退到书封，清除图例不会改动书封。

发布快照固定图例、说明和具体衍生图 ID，并通过 CatalogPublicationMedia 保护引用。图例字段及其 FK 只触发 Public 展示处理，不重新执行正文或向量索引。正式恢复发布复制旧快照，在新版本号下重新使用其精确图像引用，不覆盖后来的编辑草稿。

后台新工作台和旧复核页共用图例编辑组件。媒体库可按推荐用途选择图片，后台 JSON 预览有生成契约，二进制预览仍受原管理权限保护。组件在工作/版本上下文变化时重新建立状态，错误不会冒充无图。公开推荐使用独立图例及其 srcset，普通书目仍优先书封；旧图例没有衍生图时不错误套用书封 srcset。

新选择接口和 metadata JSON 入口已纳入 verified OpenAPI。旧兼容上传接口仍保持 12 MB 上限，共享媒体库为 20 MB，均执行内容/MIME/后缀与像素限制。

## 学者肖像

Person.portrait_rendition记录首选肖像，保留原portrait路径作为旧图片兼容。新增选择不改写或删除原文件。清除在正式发布时只清除引用，旧文件路径记入审计。所有新选择复用原媒体校验、原件去重、固定metadata_snapshot及4:5焦点裁切，不另建文件存储。

肖像选择使用ScholarProfile的portrait_selection编辑字段，包含当时Person ID、具体rendition ID和原路径。只允许当前学者身份及合法portrait类型，不能输入任意文件路径。读取指纹对应同一份已显示草稿，选择和清除时重新锁定核对；旧页面不能覆盖后来的肖像草稿。媒体准备后选择失败仍保留已生成版本，不删除媒体。

学者元数据与肖像保存组合到同一当前编辑草稿，保留原person子字段、名称及旧修订，不因随后换图丢掉先前简介修改。仅肖像变更触发Public投影，仍复用现有知识发布事件。公开人物必须已核验且ScholarProfile已发布，公开图片端点只接受当前选中组的具体rendition。私有草稿使用受后台权限保护的媒体端点，原件不进入公开响应。旧书目快照不因此改写。

EditorialRevisionMedia保护编辑前后引用的具体媒体版本。更换或清除图片后仍不能常规删除已被修订引用的rendition或该修订。旧二进制PATCH兼容入口仅接受独立肖像上传，转为共享媒体和待发布草稿，错误保留为错误。新前端从同一媒体库选图，不再在保存学者时隐藏地另发旧图片上传。

公开学者卡片和详情使用同一响应式肖像组件，展示已确认的说明和精确srcset。服务器渲染保持正式同源路径，独立本地Web预览在浏览器接管后使用明确配置的API源，避免把本地缺少反向代理误写为图片不存在。
