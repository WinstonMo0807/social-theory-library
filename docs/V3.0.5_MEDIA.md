# 媒体资产与封面发布

当前已完成媒体库及 Work 封面的第一切片，Person、KnowledgeNode、ReadingPath 和推荐图统一接入仍待完成，不能称整个媒体升级完成。

原图片保存在独立 MediaAsset，以 SHA-256 去重，保留来源、使用权、许可、署名、alt 和焦点。只接受实际内容、MIME 和后缀一致的 JPEG/PNG/WebP，限制 20 MB 与 2400 万像素。媒体默认不公开，后台文件接口需要原管理权限。

衍生图为独立 MediaRendition。书封保持比例，肖像和横幅支持焦点裁切；宽度档位 320/640/1280，不放大小图。相同参数复用，焦点变化保留旧结果。公开修订以 CatalogPublicationMedia 的真实保护 FK 引用具体衍生图，不能由常规删除误删已发布图像。小图 srcset 去重并保留主图。

Work.cover_rendition 是媒体封面选择，旧 cover 文件字段作为兼容读取路径保留。已发布作品选择媒体进入原 EditorialRevision，正式发布才捕获媒体说明、许可和精确 rendition ID。随后修改 MediaAsset 不会改变旧活动快照。旧 PDF 封面入口保留，并在人工选择 legacy 文件时清除媒体选择，避免双来源冲突。

衍生图同时保存当次选择的说明、来源、许可和署名。仅编辑这些资料也会产生新的版本 ID，管理员重新选择后才能进入书目草稿，发布前可核对文字差异。资料不会在准备和实际发布之间随源对象更新。后台完整页面预览使用已保存的编辑修订及私有图片 URL；公开页面仍只服务活动版本。Model.save 与 QuerySet.update 保护原件及衍生图的文件身份和已保存资料，不声称能阻止直接 SQL 或存储层覆写。

公开图片端点只接受当前活动快照登记的 rendition ID，不能借 UUID 读取其他私有媒体。书卡使用 srcset 选择适合尺寸，原件不进入公共响应。框架 Image 组件对开发机私网地址的防护保留；已由后端缩放的图片用原生 picture/img 直接由浏览器读取。
