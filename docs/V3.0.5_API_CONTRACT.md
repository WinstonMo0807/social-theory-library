# API 契约进展

当前只对明确列入 verified 范围的端点严格生成，不代表全量 API 已有可靠 OpenAPI。

当前 verified 范围还包含发布命令及媒体部分端点。推荐图选择、公开图片元数据、后台独立 JSON metadata 路由由真实 serializer 生成类型，支持明确 edition_id 上下文。旧兼容图片 GET 可返回二进制，不将其错误声明成仅 JSON；旧上传/删除入口复用同一响应生成逻辑，但全量旧接口契约覆盖仍未完成。

## 已接入

真实 `CatalogingSessionCreateSerializer`、`CatalogingSessionSerializer` 与相关输入 serializer 通过 drf-spectacular 0.30.0 生成 OpenAPI，openapi-typescript 7.13.0 生成 TS。`web/lib/api/cataloging.ts` 使用生成类型。`npm run api:generate` 更新两个产物，`npm run api:check` 在只读内存数据库环境重新生成并比较；漂移退出非 0。generated 文件不手工修改。

`config/schema_urls.py` 选择原 URLPattern，不另建 API 实现。schema 只供具后台权限的用户读取。错误 JSON 保留旧 detail/error，同时统一 code/message/field/severity/details；成功响应和 PDF 不改变。

官方工具依据为 [drf-spectacular](https://drf-spectacular.readthedocs.io/en/latest/readme.html) 与 [openapi-typescript CLI](https://openapi-ts.dev/cli)。固定版本以避免生成结果随安装时间漂移。
