- 每批最多5份PDF，逐项失败和重试；默认本地解析，不自动访问外部书目或AI来源。书目助手可显式获取整条候选，仍通过现有来源、确认、人工锁和撤销机制处理。
- 桌面列表与推荐中的馆藏/原文链接在新标签页打开，窄屏当前页打开；馆藏详情至Reader保持原导航。无阅读文件的版本不显示可用PDF入口。
