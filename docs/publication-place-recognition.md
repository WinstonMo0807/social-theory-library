# 出版地识别与人工校准

适用版本：2.2.3
适用文献：图书。期刊论文、学位论文与研究报告保留数据接口，但不会在入库时强制填写出版地。

## 1. 接入位置

出版地识别沿用现有 PDF 入库任务。文献完成页面解析和元数据候选生成后，系统分析当前版本的题名页、版权页、前 10 页和最后 5 页。文本型 PDF 使用已有文本层；候选页面没有足够文字时，只对这些页面调用 PaddleOCR，不重复 OCR 全书。

识别结果显示在元数据复核页的“出版信息识别与证据”区域。管理员可查看候选值、地点类型、置信度、来源、对应出版者、对应年份、证据原文和 PDF 页码。点击证据页可打开阅读器，跳至该页并检索证据原文。

## 2. 证据顺序

系统按以下顺序生成候选。

1. PDF 题名页、版权页、CIP 页和封底书目信息中的直接证据。
2. 与当前 ISBN 和版本相符的 MARC 21、ONIX 或 Open Library 记录。
3. 现有元数据候选中的明确出版地字段。
4. 出版社规范库中的可能城市。

出版社规范库只产生待核候选，最高置信度为 0.60。它不会自动写入引用。PDF 元数据也只作为辅助来源。

## 3. 地点类型

每条证据独立保存地点类型，避免把地址、印刷地或发行地当成出版地。

- `publication`：出版地
- `distribution`：发行地
- `printing`：印刷地或制造地
- `production`：生产地
- `publisher_address`：出版者地址
- `degree`：学位授予单位所在地
- `archive`：档案收藏地

MARC 21 的 264 字段按第二指示符解释。0 为生产，1 为出版，2 为发行，3 为印制或制造。260$a 按出版信息候选处理。不同权威来源给出互不相容的出版地时，系统保留全部候选并转为人工复核，不会静默覆盖。

## 4. 确认状态

- `auto_confirmed`：置信度至少 0.90，有直接或权威版本证据，而且出版者、出版年或 ISBN 与当前版本相容。
- `needs_review`：间接推断、OCR 质量不足或来源冲突。
- `manually_confirmed`：管理员确认了候选。
- `manually_corrected`：管理员输入了修正值。
- `unknown`：没有足够证据。

人工确认和人工修正优先级最高。重新识别默认只替换自动候选。管理员没有明确要求覆盖时，系统保留人工值及修改历史。

## 5. 多出版地与版本一致性

数据库保留全部原始值和规范值，并保存主出版地、显示顺序、来源记录号、证据页、证据文本、置信度及确认人。London 与 New York 等同一版本记录中的多个出版地不会被当作彼此冲突。引用生成器读取当前版本已经确认的主要出版地，不从出版社总部或模型常识补全。

出版地、出版者、出版年、版本与 ISBN 必须来自同一版本。外部记录与 PDF 直接证据冲突时进入人工复核。

## 6. 引用更新

确认或修正出版地后，版本兼容字段立即同步。GB/T 7714—2025、APA、Chicago、MLA 和 Harvard 继续调用各自的 formatter。GB/T 7714—2025 在出版地确实未知时输出 `[出版地不详]`，不会输出没有方括号的“出版地不详”。

## 7. 隐私、成本与回退

本地规则与 PaddleOCR 为默认路径。外部书目查询只传 ISBN 或书目字段，不发送 PDF 正文。外部来源不可用时，入库、在线阅读、下载和原文检索继续运行。识别失败会留下待核或 unknown 记录，并在处理历史中保存可读错误摘要。

## 8. 管理员操作

1. 在馆藏项目或元数据复核中打开图书。
2. 检查出版信息候选及当前版本信息。
3. 点击证据页，核对 PDF 原文。
4. 选择“确认候选”，或填写正确地点并保存校正。
5. 保存元数据。详情页、搜索索引和所有引用格式随当前版本字段更新。
6. 需要重新分析时使用“重新识别”。人工值不会被默认覆盖。

## 9. 数据回退

2.2.3 的迁移只增加出版地证据、出版社规范和修改历史表，并保留 `Edition.publication_place` 兼容字段。回退迁移会删除新增表，不会删除原有版本字段。回退前应先导出人工校准记录。
