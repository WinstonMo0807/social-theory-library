# J/K 品牌加载动效发布 · 2026-11-15

用户明确选择J/K并授权公网。本轮仅将已确认的两款动效接入共用LoadingState及BrandLoadingMark，保留已发布E书库、C荐书、B读者中心与香港回源。

| 原呈现 | 发布后 | 作用 |
| --- | --- | --- |
| L7金色书签左右移动 | J双页从两侧相合，原标识随后显现 | 用纸页空间承接原黑金品牌 |
| L7是三款中的一款 | L5、L6、J、K四款等概率随机 | 同时采用用户选择的J/K，原两款保持 |
| 单一书签变化 | K从下向上渐变显影，金线与双语名称随后出现 | 保留留白与稳定的标识轮廓 |

J/K均为4.8秒CSS循环，J右页错开110毫秒；不增加运行依赖、图像下载或固定等待。随机选择仍由首屏SSR完成，客户端局部等待沿既有挂载逻辑选一次。三种尺寸使用比例定位，原品牌矢量直接复用。系统减少动态效果时不启动动画；站内data-reader-motion=reduced同时取消遮罩，完整静态标识不会消失。真实内容就绪由既有业务卸载加载组件。
