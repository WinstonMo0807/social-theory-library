## 原有身份与服务

Subdiscipline继续使用原有独立实体，Discipline和Topic也不转换成KnowledgeNode。正式知识关联通过现有KnowledgeNodeSubdiscipline读取；未映射的旧TheorySchool仍保留原ID与原详情链接。只有显式且安全的LegacyKnowledgeMapping可以指向规范节点，同一节点已经直接关联时合并展示并保留旧关联身份。

子学科API复用现有列表/详情路由及Scoped Search。列表只读取卡片所需基本字段，不为每张卡加载所有人物、文献、路径与正文；详情保留完整投影。搜索支持子学科本身、已确认公开关联概念及主题；公开搜索结果始终返回真实Subdiscipline ID，不使用历史镜像ID。未公开所属学科和父级返回null，筛选与关联人物同时核对公开资格。代表人物的说明来自真实人工关系；没有精确原文外键时不伪造来源链接。

公开核心文献使用正式发布快照，支持主版未公开而次版公开的作品。旧works兼容响应与新core_works均保留准确版本。核心卡与关联依据可能属于不同出版版本，两者分别携带自己的edition/asset/document revision，依据另显示真实版本标签、题名、页码和入口，不将次版摘录冒充主版正文。

依据来自既有WorkSubdisciplineRelation与已发布内容编排。读回重新检查文件属于作品、当前正式全文修订、实际页及当前可见范围。替换、撤回、缺页、私有文件不得继续回传旧摘录。核心文献沿既有48项规模分页，`works_page`与`works_pagination`提供真实总数、当前页及总页数；页面提供前后页入口，不再静默丢弃第49项以后的记录。文献关系依据随当前文献页返回，已发布内容编排依据独立保留。阅读路径只来自包含已确认本子学科知识节点的实际公开路径，不能因同学科或同名而推断。

新增公开目录是同一模型的有界投影，没有第二套馆藏或新数据库表。KnowledgeNode只纳入理论传统、概念、争论、研究问题；独立子学科使用单独分支。父级可跨规范节点类型，按实际FK呈现，不猜“古典”“当代”分类。草稿父级不输出ID或名称；循环和过深层级最多返回20级，并显式提示截断。

## 契约与交互

`GET /catalog/theory-system/directory/` 接受type、discipline、parent、q和page，每页20项。返回公开学科、当前类型、父级和返回路径、当前页分组、真实直属子项数及分页总数。未知或未公开父级/学科返回404，无效条件返回400；空目录返回200及空分组。子项数不受关键词影响，展开时清除关键词，避免按父名搜索后误报无子项。

目录选中详情独立加载，单条失效不清空目录。概念类型来自实际关系端点字段。精确来源依次使用节点依据、关系依据、作品关联依据和已确认用法；只有整本阅读入口时标为“查看馆藏原文”。目录切换时间线保留其支持的学科/关键词，切换关系图保留其支持的学科与规范节点中心。

现有子学科列表增加featured过滤，详情增加href、children、key_questions、core_works、reading_paths和sources；theories/scholars/topics补足现有关系。discipline/parent明确可空。总览与学科计数改为独立子学科计数，理论数量合并primary_discipline、正式关联及安全旧映射后去重。

OpenAPI保留原185路径，新增子学科既有列表/详情契约与目录投影，共188路径。没有新迁移或对数据库的数据操作。
