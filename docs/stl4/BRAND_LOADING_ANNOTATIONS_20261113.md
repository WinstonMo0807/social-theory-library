## 当前实现

- 首次路由/账户入口：screen，200–300px标记及既有双语名称；工作区：164px品牌；列表：品牌加内容骨架；PDF：纸页加载；局部选择/字段：compact；短操作：inline/原按钮旋转图标。
- L5/L6/L7每次挂载随机，停留期间不换；减少动态效果时静止。没有人工延时、虚构百分比或完成提示。
- 批注侧栏默认全部，可筛选高亮/划线/笔记及当前页，文字删除按钮。对已有批注右键提供精确删除项；图层仍不截获拖选，通过屏幕实际框命中，适用缩放/旋转及多行。
- 本书研究选材按项目列出，移除只调用原 selections/remove；撤销调用 undo，保持备注和原顺序。原项目和其他选材不删除。重复提交受锁保护、请求携带本人及版本，失败读回确认，不先假装成功。
- 原书签删除入口保留。不会把检索高亮、公共原文或其他读者资料当成本人的批注。
