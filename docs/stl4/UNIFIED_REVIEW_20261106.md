## 怎样逐步批注

1. 从首页实际导航进入要看的页面，直接使用浏览器批注也可以。
2. 需要圈画和持续保存时打开 `/admin/visual-review`，选择PDF视图或填写当前本站路径，在右侧真实页面操作到需要说明的位置。
3. 点击“绘图与批注”，圈画并填写修改要求，再点击“保存批注”。可从“已保存批注”继续打开。
4. 新欢迎页没有旧PDF对应图时，可在同一工具填写 `/welcome` 或 `/admin/welcome`，并在说明里写清新的用户要求优先；不假装旧首页图就是新欢迎页终稿。

后续按具体批注修正。B只表示已实现待验收，D表示开发项关闭；没有具体失败或规范违背证据时，不扩大开发范围。全站像素一致、所有有数据状态、全部权限操作、长期稳定及公网发布仍未通过最终验收。
