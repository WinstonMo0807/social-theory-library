## 字体判断与使用许可

| 组合 | 实际观察 | 用途判断 |
| --- | --- | --- |
| Noto Serif SC 标题 + Noto Sans SC 正文/控件 | 标题保留书刊感，小字号表单和说明更清楚 | 默认推荐 |
| 全宋体 | 文献气质明显，密集表单中的细笔画不够利落 | 保留比较，不作默认 |
| 全黑体 | 扫读清楚，但编辑页面更像操作工具 | 保留比较，不作默认 |
| LXGW WenKai | 笔画柔和、手写感明显，密集后台层级较弱 | 阅读偏好候选，不作全站默认 |

三款字体均使用 SIL Open Font License 1.1，可免费使用、嵌入与再分发，也允许商业用途。它们并非无版权作品；分发时保留版权声明与许可。Noto 来源和逐文件散列已在字体目录中，新增 `WENKAI-SOURCE.json` 与 `wenkai-OFL.txt` 记录文楷来源、版本及转换方法。

- [霞鹜文楷官方仓库与许可](https://github.com/lxgw/LxgwWenKai)
- [STC Simplified Technical Chinese](https://github.com/daimonia-ai/STC-Simplified-Technical-Chinese)，本轮参考其 for-web-dev、用词及 anti-echo 规则，没有将检查器加入网站运行环境。

比较入口使用同一路径上的 `#typography=A&font=balanced`、`song`、`sans`、`wenkai`。切换后继续导航维持当前标签页选择；打开新标签页默认推荐组合。
