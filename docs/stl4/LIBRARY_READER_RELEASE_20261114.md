- 首页原首屏、继续阅读、特别策划、学者、主题保持。最近入库列表减轻边框；C 荐书默认选中真实书目，右侧导读区扩宽，可换书及打开真实作品。
- 读者中心所有 account 路由共用 B 工作台，9 栏导航、可折叠侧栏、次级导航、Ctrl/Cmd K 快速查找、新建菜单、研究材料栏展开收起。概览、笔记、研究列表/详情/比较/反证/回放、体检提交/解析/报告/问题、计划、书单、来源、分享、小组、确认笔记、资料/历史/收藏/投稿、隐私/导出页面使用同一外框及各模块适配。
- 选中条目、拖拽上传、勾选检查项、处理中/成功/错误、按压、弹窗与局部展开提供对应反馈；键盘输入和减少动态效果偏好分别处理。原 owner 检查、API、数据与任务状态保持，不模拟成功。
- 主导航常驻读者中心，抽屉合并原我的资料/账户设置入口。退出和账户切换仍在原菜单，资料与设置在读者中心内。
- 修复混合检索学者四列长传记与头像拉伸，文字排序按钮不再受图标宽度约束。

## 排查证据与修复边界

1. 实际 `/catalog/works/` 按 edition 日期排序会因一作品多版本而重复返回。新目录改用作品级 `created_at`/`title` 排序，保留服务端分页；不通过前端去重截断当前页。两种排序全部 3 页各 57 条，57 个不同作品 ID，和接口总数一致。
2. 外层 route-content-transition 为 flex，内部 container-type 会使新工作台按内容最小宽度收缩。给工作台明确 width:100%/flex/min-width 后复核桌面正文宽度。
3. 旧账户菜单额外占整行，且与合并入口重复；从该页头位置移除，原抽屉账户操作仍保留。
4. 次级页面旧面包屑、内层页框重复占位，按新工作台范围统一；保留正文、表单标签、错误信息与业务动作。
