# 主编型图书的发布校验修复

## 复现与原因

《社会运行论及其发展》已按版权页登记李强、洪大用为整部出版版本的主编。原校验把除整期期刊外的所有文献都固定要求作者，导致主编已确认的论文集仍被阻止发布。

## 改动

图书没有作者而存在整书主编或编者时，将必填责任字段替换为实际角色，仍走字段人工确认与原发布流程。译者、研究对象和章节范围的编者不能满足这一条件，其他文献类型的作者要求保留。工作区确认、正式发布检查与队列使用相同含义。引用元数据记录editor，不把编者写入author。

## 验证

本机SQLite执行test_edited_book_responsibility和原作者必填回归，共9项通过（69.23秒）。覆盖两种编辑角色、清空责任者后的阻断恢复、译者与研究对象不替代作者、章节编辑不替代整书作者、论文和学位论文仍要求作者、既有作者不被编者绕过。

生产基线与四份修改文件逐行比对，仅含本项修复。发布包在本机生成，NAS只加载镜像、独立启动检查并切换api服务；保留其他处理进程、原件和数据库。本次无迁移，回退仅恢复API镜像，不恢复旧数据库覆盖后续策展。
