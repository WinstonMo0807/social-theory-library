## 共用问题及小范围修正

- HTTP 内网缺少 `crypto.randomUUID` 时，多个按钮在发出请求前报错。66个文件改用已有 `createRequestKey`，保持UUID格式与安全随机数、固定请求重试和原权限。上传标识及编目会话也复用该函数，不采用时间戳/Math.random作为替代。
- 分享、分享记录、小组邀请、私人书单复制直接访问缺失的Clipboard API时，既有手动复制分支未执行。统一异步包装让此失败进入原有兜底，不宣称已复制。
- 旧本机研究转存需要安全摘要；HTTP环境缺少WebCrypto时明确说明使用HTTPS入口，并保留原始导出。没有改成弱摘要、随机身份或重复导入。
