- 遍历当前前端引用的 188 份 CSS，调整 159 份，逐文件记录见 `READABLE_TYPE_COVERAGE_20261107.csv`。这是源码覆盖，不等于每个路由每种状态均已视觉验收。
- 复用本地 Noto Serif SC 与 Noto Sans SC 的 Unicode 分片 WOFF2、400–700 字重和 swap 加载。未新增字体下载、依赖或重复大字库。标题保留宋体气质，正文和功能文字以现有无衬线体系为主，用户外观与字体设置继续生效。
- 基础字号下限：辅助信息 14px，功能与普通正文 16px，阅读正文 17px；舒适档各加 1px，大字档各加 3px。原本更大的标题和文字保留，不将所有内容改为同一字号。

- 中性辅助文字用 `#5c6267`，正文重点用 `#343b3c`；夜间对应 `#c2c4bd` / `#e8e7e0`。按指定色对计算，辅助文字对白色约 6.18:1、对纸白约 5.63:1，夜间辅助文字对 #20221f 约 9.10:1。这不是全站所有动态背景的对比度认证。
- 保留 Logo、品牌资产、PDF 页面坐标与 SVG 图示几何；未修改 B 版及历史比较页来冒充当前 A 版成果。必要来源、隐私提示和状态信息保留。
