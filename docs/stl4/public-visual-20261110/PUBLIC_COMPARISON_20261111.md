## 原验证为什么没有揭示问题

已有accepted.json中，80个入口有44个只记录到1—3个节点的布局属性变化，2个为0、19个为4—10、15个超过10。PV048为2，PV068为1，PV012为12。

这些计数来自固定的padding/margin/gap/gridTemplateColumns/borderRadius/boxShadow/minWidth/maxWidth属性比较，不是视觉质量、改善幅度或设计相似度评分。尤其PV068的唯一差异是block容器的gap，能让属性比较通过，却不能证明用户看得到改变。不能再用78个入口有变化、200张截图或76张设计图替代设计落地证据。

复看A01、A35与R01生成图，剔除不符合用户约束的品牌、导航、字体、颜色及业务表达后，其主体比例与信息密度也未充分落实。不能为了接近图片擅自实现图中不存在或被后续限制的功能；应基于现有控件与内容重新完成允许范围内的布局。
