# 当前范围与视觉方向

本轮最高边界是 SCOPE.json 与用户最新指令：只变动读者中心和管理中心主体排版视效；任务分类栏、端口设计、其余前端内容不变。登录页、登录弹窗、所有相关弹窗／抽屉及公网加载动画不变。现有品牌、字体及字体颜色必须保留。手机只通过代码适配，不继续生成图片。

这是已有系统的受限排版调整，非新视觉世界。前期整站／手机／弹窗图片仅历史参考；原有导航、字体、颜色、文案、接口和交互均高于图片。现有桌面图 76 张映射到本轮入口；图中不存在的操作或错误品牌不实现。完整生成来源见 DESIGN_IMAGES.json；唯一覆盖清单为 COVERAGE.csv。

## Direction contract

THESIS：通过主体列宽、间距、密度和对齐，让阅读资料、编辑字段与现有预览更容易使用。保留现有信息架构和功能。

OWN-WORLD：沿用本站纸白、白色内容层和黑金品牌。字体、字号、字重、行高及字色均读取现有 CSS；不新增字体或颜色变量。主体间距采用 12、16、20、24、28、32px，内容边界采用原有颜色和局部 3px 圆角。不要触动任务分类栏。

STORY：读者继续已有阅读和研究；管理员定位对象、修改字段、核对既有实时预览并按既有规则保存。功能、文案、数据和操作路径原样保留。

FIRST VIEWPORT：原有页头和分类导航占据原位置；主体标题与动作保持邻接。资料列表使用可读列宽，编辑保留表单与真实预览，OCR 书目信息不挤成窄列。窄屏通过主体自然换行和原有面板切换适配。

FORM：用户指定的现有品牌与桌面图空间参考；不进行随机风格选择。用户已明确生成图的品牌和导航不好，要求严格沿用现有，并补充字体、字色以及只变动中心主体的约束。此次采用代码层受限改造，旧 comp 全图复刻流程不适用；没有创建或伪称完成任何 comp-diff 分数。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 实现与验证边界

CSS 作用域在 .admin-content 与 account 布局包装内，避开导航、aside、弹窗、菜单、加载动画、公开预览与 PDF 正文。CSS 模块只追加布局规则。静态范围检查以 7c4e4a0d 为比较点，保留原有 CSS 源码，业务 TSX 只新增样式 import 和 display:contents 包装。

浏览器比较实际运行样式，包括通过 link 加载的全局样式和 Vite 模块样式。PDF 文本层随画布可用宽度重绘，不纳入 UI 字体数值比较；单独检查原文显示和定位入口。捕获测试发现的错误与既有问题分开记录，不能用截图或构建代替实际功能检查。

独立预览使用隔离测试库。任何图中的学术内容与运行截图的测试条目都不是正式数据。公网、原工作区和 Knowledge Core Demo 不改动。
