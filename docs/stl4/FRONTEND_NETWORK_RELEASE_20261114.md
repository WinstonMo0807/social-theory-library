追加实施：

- 菜单保持原生 Dialog 挂载，使用 opacity/transform、display/overlay 离散过渡；关闭焦点和导航立即完成，减少动态效果取消位移，不支持过渡的浏览器直接关闭。

- 首页通过服务端会话 cookie 的存在预留中性继续阅读区域。cookie 只决定布局，实际书名/封面/页码仍由既有认证和 owner 核对控制；空记录和失效会话显示相同区域内的可行动状态。不是零 CLS 保证，长书名和极大字号仍可能扩展区域。
- 所有原生模态窗锁定背景滚动；Toast 键盘关闭将焦点交给下一个反馈按钮或此前的页面控件。
- 站点设置请求限定5秒，并在同一服务端渲染内复用；其他服务端读取45秒上限。保持 no-store，不缓存私人内容，不延迟撤回生效；失败继续显示真实不可用状态。
