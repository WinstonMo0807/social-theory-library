## 使用

1. 登录后打开/admin/visual-review，按终稿编号逐张选择。参考图是PDF中的最大原始图像，不使用旧图片目录。
2. 输入本站真实路径。动态 `[id]`、`[slug]` 必须替换为实际对象；不能用虚构材料填充空库。
3. 选择桌面/平板/手机视口，在真实页面执行操作；绘图时冻结页面交互，以免笔迹与内容错位。
4. 画出位置并填写期望行为，保存后方可切换参考页或继续新一条交互。绘图记录当前滚动位置，不是页面截图；内容更新后应回看位置。
5. 保存记录可重新打开、调整、标为已修正待确认、导出JSON用于后续开发。未知保存回执先查回或停止，避免重复保存。
