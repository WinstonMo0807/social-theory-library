# 学者卡片留白与交互调整 2026-11-10

用户指出公网学者页及聚焦栏目肖像两侧留白过多，要求优化排版与交互视觉。延续本对话上一轮学者页面公网发布授权，本轮仅调整前端样式，原肖像、资料、媒体用途权限和发布版本保持。

## 已确认原因与修改

`scholar.module.css`把推荐肖像设为2.85∶1，全部学者设为2.5∶1；使用完整显示的方形图时，图片宽度仅占容器约35%和40%。另一条手机覆盖仍强制1.8∶1。此为实际源码与用户截图支持的问题，并非图片上传失败。

- 推荐区改为肖像在左、姓名和研究方向在右。大屏4列，中等宽度2列；手机为95px方形肖像与文字并排。
- 全部学者、独立索引网格、首页自动聚焦及后台编排聚焦使用方形画框，继续contain，不裁脸、不加遮罩、不缩放悬停中的人物。竖幅原图保留必要的窄边，未重新生成或改动图片。
- 全部学者随宽度调整6/5/4/3列，手机沿用可读的一列图文。名称自然换行，移除试排中多余的姓名预留行；首页研究方向由单行改为最多两行。
- 悬停/键盘聚焦用边线、名称下划线和3px箭头位移表达入口。键盘保留可见焦点，减少动态效果时关闭位移和过渡。没有自动轮播、模态窗口或新依赖。

代码范围共三份CSS：`web/components/public/scholar.module.css`、`web/styles/features/home/home-stl4.css`、`web/components/public/home-curated-section.module.css`。两条聚焦入口均已覆盖；人物详情、筛选/检索、默认图分配和媒体权限逻辑保持。
