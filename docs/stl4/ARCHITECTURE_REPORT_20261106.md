# STL 动态架构汇报交付

2026-11-06。本次交付独立内部展示应用，不实施书库业务变更，不执行生产切换。

## 当前成果

- 本地入口 `http://127.0.0.1:5274/?scene=overview&phase=2`，六个场景、手动阶段、播放暂停、单阶段重播、节点逐层聚焦、全局返回、键盘和全屏。
- 47 个有依据的展示节点、31 条分类关系。151 个实际页面入口，760 个前端源码文件静态扫描、3,118 条解析成功的本地导入边。静态导入包括类型及未必运行的模块，不能当作全部页面运行覆盖。
- 核心业务人工核对范围包含页头/后台导航、探索和 Reader 路由、Discovery 会话与客户端、阅读/引用/研究选择、本人过滤、入库处理、发布命令、目录导出、设计变量、共享组件及服务声明。
- 来源节点保存文件、锚点、行号和 SHA-256；关系也保存独立证据。架构含义由审计确认，提取器只维护位置和清单，不自动推断功能完成。
- 六张 3840×2160 PNG 与研究工作流 1920×1080、16.8秒、25fps WebM（VP8、无音轨）。页面可继续导出当前场景。使用既有 React/Vite/Playwright；视频补充安装了 Playwright 官方 FFmpeg 工具，没有新增业务 npm 依赖。

## 事实修正与边界

1. 首页与欢迎页分别存在，欢迎页不强制取代首页。
2. 访客可浏览网页；探索、PDF 与下载需登录。私人研究 `PrivateRecordViewSet` 按本人过滤；后台按能力授权。
3. 当前 OCR 是 RapidOCR，旧 PaddleOCR 文档不作为当前主链。
4. 发现、证据、阅读和研究共用作品/版本/文件/正文修订/页码标识。结构归属、页面导航、服务调用、数据流与设计复用使用不同关系类型。
5. 自动目录在本轮制作过程中出现新的项目记录。已经同步读取 `AUTOMATIC_OUTLINE_20261106.md`，把自动目录从未完成条件调整为“已实现，待扩大验收”；两份扫描件/11 项检查是另一轮的记录，本汇报任务没有复测或操作原件。
6. 私人研究中转接口已在代码接入，与 STL 智能助手/本地检索模型分开；真实地址/密钥配置及外部调用未验证。
7. Apple/Google 登录仍有明确缺口；RAG/LLMWiki 未决定，政策研究已暂停。管理端的正式预览路由继续列入管理入口；视觉实验页和暂停的政策页单独标注。

## 实际验证

匿名独立上下文读取首页、欢迎页、理论页均为 200；探索实际转到 `/login`；`/api/catalog/discovery-search/` 返回 401；health/ready 返回 200。这不是业务健康、队列完成或模型质量证明。

汇报应用定向检查通过：六场景布局、节点/内部模块与返回、路由搜索、暂停不自动推进、当前阶段重播、键盘、全屏、减少动态效果、4K PNG 下载、无业务 API 代理及跨来源导出拒绝。尺寸为1920×1080、1366×768、1280×720、1024×768，另390宽无横向溢出；手机是等比缩小画面，不作为正式汇报尺寸。Codex 浏览器也实际进入/退出全屏并查看私人研究详情。

首次运行发现节点文案溢出与页脚拥挤，已修复并复测。第一次独立类型检查缺 CSS Module 声明，补充局部声明后退出0。最初选用的5196端口被其他进程占用，改为5274，没有结束其他进程。保留初次失败截图/日志，不把未运行的业务检查计为通过。

本轮命令、结果及限制详见 `tools/architecture-report/README.md`。截图与验证记录为 `output/playwright/architecture-report/`，导出成品为其 `exports/`；生成的数据、截图、视频和构建不提交 Git。
