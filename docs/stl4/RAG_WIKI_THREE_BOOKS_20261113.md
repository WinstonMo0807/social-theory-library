## 实际业务核验

1. 每条候选引文经指定窗口和不可变页面快照逐字校验，偏移为原始 Unicode code point。连续 OCR 行只在同页、同证据立场且间隔为原始空白时合并，避免把每行变成一条独立学术证据；正文、历史结构、历史锚点不覆盖。
2. 四次身份比较读取了馆内类型、异名、人物资料及相关作品，结果为待审关联建议，不按同名自动归并。周雪光对韦伯的解释保留周雪光为主张者、韦伯为被引用参与者，未变成直接读取韦伯原著。
3. 在隔离候选库的外层回滚事务中，实际调用同一 `review` / `apply` 服务，试验关联四个已核对的现有学者身份，并应用依赖闭合的全部建议。三组分别保存 19、19、18 项，blocked 均为空；重复相同请求返回相同回执。所有原人工区块均保留。
4. 上述试跑整个事务强制回滚，未发布，提交后的回调不执行。回滚后 Entity=49、Assertion=7、KnowledgePage=9、ChangeReceipt=4，与试跑前一致；56 项仍 pending。它验证保存路径，不等于已经得到管理员认可或已经完成公开发布。
5. 浏览器实际读取三书范围、窗口记录及待审列表；《以利为利》陈述打开固定修订 PDF 39 / 印刷页 35。知识区块“当前内容 / 修改后”切换可见原人工正文和带新增标记的局部 patch。截图仅存忽略目录 `tmp/delivery/wiki-review-20261113.jpg`。
