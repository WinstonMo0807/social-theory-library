# 账号头像与策展署名同步

用户要求读者在自己的账号界面看到头像，公开页面展示策展人的头像；评论功能尚未决定，不新增评论入口。

## 证据与实现

- 原 `public_editorial.public_metadata` 只读取独立素材头像，与 `AccountAvatar` 无关联。首页、列表、详情共用该投影，因此均不会随账号修改更新。
- 原 `ProfileAvatarEditor.accept` 保存后只更新本组件，其他 `AccountAvatar` 不会收到更新。现增加同页面事件和同源标签页通知，载入仍须通过原账号鉴权。
- `admin-shell.tsx` 原来固定显示姓名首字母；现与读者账户菜单共用 `SelfAccountAvatar`。复用现有尺寸和裁切，未另建头像控件或存储。
- 新策展草稿默认关联创建者账号；编辑页可保留原策展人、改用本人头像或单独设置图片。显式素材头像优先保留。不能提交任意其他读者账号编号来公开其头像。
- 公开头像通过已发布策展的专属地址提供，按实际生效的发布版本检查署名和关联，不暴露账号编号、邮箱或私人资料。管理预览只对有该项目访问权限的后台用户开放。
- 更换/移除头像后，公开投影读取最新修订，不复制头像到素材库，不要求逐篇重新发布。头像响应 `private, no-store`，URL 含修订号；旧 URL 也读取当前头像或返回 404。
- 署名文字、策展正文和发布时间不随头像更新。公共页面在下一次访问/刷新时显示最新头像；没有向所有已打开的公共页面持续推送图片。
