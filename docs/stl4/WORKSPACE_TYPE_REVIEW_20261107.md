## 核对方法与限制

- 使用已登录浏览器只读查看真实页面，保存截图并读取实际字体、行高和元素宽度。缩略图/账户等截图只存本机忽略目录，不提交真实账户数据。
- 桌面 1440、平板 768、手机 390 与 320；按修正范围补充大字和夜间核对。每个页面的实际宽度单独记录，不表示所有页面都覆盖四种宽度。
- 表单和弹窗只打开/关闭，未保存、删除、发布或改变角色。研究结果和私人详情缺少记录的状态明确保留为 B。
- 途中公网两次读取超时，同版内网随后能读到真实数据；这不是字体缺陷。公网发布后另行回看，不以加载占位图代替完成截图。
- 构建、候选与正式发布结果将在实际完成后追加。历史失败工具调用保留，工具参数错误不登记为产品缺陷。
