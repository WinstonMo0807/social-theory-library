## 状态与真实依据

原文查询解析真实 scope 后，在原 session.results._documents 保存最多200个出版版本身份、发布修订、来源修订及本轮状态；不复制题名、正文或私人数据。列表超出200明确提示缩小筛选，不能把200当整个馆藏数量。全文查询仍使用完整允许范围。

来源必须满足当前正文资格，并有同一索引代/修订的完成记录及实际就绪索引文档数量，才标记正在查询。索引未完成只记等待索引；就绪本身不是查询完成。原检索返回并沿 generation/task_id/status CAS 保存时，才更新完成、部分或失败。取消、过期和迟到任务不能回写。没有返回候选时说明“本轮未返回直接材料”，不虚构低相关评分、不宣称逐章阅读。该语义补足 PDF 的无材料状态。

读回按当前公开修订、权限和同一来源身份重新取书目，撤回后遮蔽，更新后显示需重新检索。实际可见原文数来自当前已物化、重验和去重的材料。公开版本列表最多6项，入口指向真实版本详情，再由该页核对阅读资格。元数据批量核对分类与关联，不按每张卡片重复查库。

## 范围命令

POST `/catalog/discovery-search/{id}/remove-document/` 接受 edition_id 与 expected_generation，沿原本人/匿名能力令牌权限。只允许本会话文献身份，最多排除200个，响应未知时重复同一移除幂等。

排除保存在本会话内，不修改原文件、馆藏、收藏、笔记或原过滤。后续基础/深度检索 scope、已得材料读回和同书上下文均应用排除；单纯前端隐藏不成立。正在执行时先取消旧代次，再沿原恢复机制继续其余范围，原有效材料保留；旧任务即使迟到也无权保存。失败/完成会话的移除不自动运行新任务。

前端接入文献状态筛选、材料数量、查看结果定位、公开版本弹层、调整范围及移除。来源变化后版本弹层不保留旧书目；未知写入结果可重试同一对象。移动端沿现有暖纸色抽屉和列表，按MASTER采用炭黑/暖灰/砂金；未运行截图对照。
