# RAG 与持续 Wiki 的实际联动

2026-11-13。本轮从 `3edfdd74` 接续，开发不等待 Mac mini。Intelligence 独立工作台不恢复，MCP 不改，公网及正式数据库不切换。本文区分实现、隔离验证与运行部署，不替代三本书的全文阅读记录。

## 已完成的业务接线

1. **问答来源**。LibraryRetrievalService 直接保留 EvidenceAnchor 的全部片段、固定正文修订和阅读 URL，不再把新锚点降为旧单页 EvidenceSpan。模型输入前重读锚点并核对当前发布及访问权限；错误修订、伪引文、已撤回来源不能进入提示词。预算截取有实际输入范围记录。
2. **已发布知识回到原文检索**。共享 `retrieve_channel` 增加来源独立的 Assertion 图分支。观点检索、Ask、连续研究及管理端检验沿用同一召回服务。图分支只返回现有索引中的原文身份，继续经过原文、版本、过滤和访问校验，Wiki 正文不冒充引文。关键词模式、精确引文、限定文本域和无图基线不启动图分支。
3. **查询内的有限图**。规范名及已确认异名最多选8个实体种子，原文前8个命中提供证据种子；最多2轮、32条来源独立陈述、64条证据连接、256片段、1200条索引候选，最终图分支最多80条。使用标准个性化 PageRank，重启概率0.15、最多40次迭代、L1收敛阈值1e-8，然后以0.35权重加入原 RRF。参数是工程初值，不是已验证最优参数。
4. **角色与来源**。一般提及不打开新的实体扩展轮次；使用、批评、继承、发展、引用、回应等保留原谓词，方向、表达身份、支持/反对/限定/语境随检索解释返回。相同姓名不合并实体，不同作品的陈述不合并。排序表达相关性，不推断认同、影响或因果。
5. **会话解释可撤回**。检索会话只保存陈述ID；每次恢复或分页重新核对陈述发布和对应原文范围。陈述转草稿或撤回后解释消失；原文自身若仍合法可读，不伪造新的解释。管理员在原文工作区查看分支数量并展开实际陈述及证据。
6. **命中位置上下文**。逻辑上下文以命中范围为中心，不总返回长章节开头；同页命中前、命中、命中后分别有原始偏移。只沿明确的脚注引用读关联注释；正文与注释共同受字符预算约束，均返回实际范围。跨页锚点及历史权限沿原协议。
7. **Wiki 人工修改接续**。人工修改目标作品页或指定专题，即使没有其他页引用它，也会更新对应编纂订阅。标题与范围进入编纂指纹，按当前编辑修订提供给编纂输入；章节分析缓存仍独立。机器应用自身产物不反复触发自身。新已发布分叉资产可成为下一次接续来源，旧来源和产物保留。

`knowledge_graph.py` 使用标准 PPR 的查询内投影，借鉴 [HippoRAG 2](https://arxiv.org/abs/2502.14802) 的段落/事实/实体联合定位思想和 [GraphRAG 局部检索](https://microsoft.github.io/graphrag/query/local_search/) 的图与原文组合。没有安装或宣称完整复现两者；没有新增图数据库、全馆向量矩阵、自动社区报告或模型请求。

## OCR 窗口与索引生命周期

`logical-node-v2` 将同页、同一父节点、同类型的短段组成检索窗口。每个原节点仍保留；单叶长度不超过120字符、窗口最多32叶/1200字符。只能跨原始空白，不能跳过正文；OCR双换行可保留在窗口内，不能跨页、跨节或跨已识别脚注。语义段落结构不因此改写。索引文本始终为 `RevisionPage.text[start:end]`，所有片段及窗口都回查哈希。

旧进行中任务没有布局版本但已有断点时继续按v1恢复，新任务用v2。主动重建的幂等键包含布局版本；片段身份也包含窗口版本。替代成功前旧索引继续提供服务，旧有效向量保留到新向量就绪。不因部署代码自动重建全馆，不清Redis或索引。没有新增schema migration。
