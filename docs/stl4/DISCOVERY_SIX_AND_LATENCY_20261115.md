## 计时方式

已登录的 Mac Microsoft Edge，经 `https://books.winstonmo.com/explore/evidence` 公网入口逐题提交。每题先打开无查询的页面、等待输入区就绪，再从点击提交前开始计时；持续读取页面可访问性状态与画面，直到六条原文和“检索完成”同时出现。因此包含提交、按需服务/排队、检索、公网往返、页面轮询与渲染，排除用户输入问题前的准备时间。数值为页面观测时间，按 0.1 秒报告，不冒充浏览器 Performance 精确事件。
