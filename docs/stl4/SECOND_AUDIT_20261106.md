# STL 4.0 第二次全工作区清点

2026-11-06。基于检查点 `6a761e02`、继承的未提交修改及当前 NAS 实际状态。此次交付是清点、证据和已授权的无用镜像清理，不是重新开发、全站运行验收或生产切换。

## 结论

1. **在已核对的部署清单内，没有发现尚未并入内网的业务源码或前端产物。** 本轮重新比较 783 个后端源码/配置文件和 3,008 个 Web 构建/静态文件，差异均为 0。这个结论不覆盖全部依赖包、所有环境变量或未运行的业务行为。
2. **有代码不等于现在能完成所有操作。** 四 worker、beat、RapidOCR、DOCX 仍停止；平台生成式模型的有效配置也为空。这是运行/配置接续缺口，不能只靠网页更新解决。
3. **上轮有一处重要误分类需要纠正。** Apple/Google 登录并非仅“没有确定的新需求”。旧最终 PDF 的账户页面已有这两个控件，当前源码仍是禁用按钮，后端没有对应登录/回调链。不能记作第三方登录已经实现、仅差凭据。
4. 条款及隐私说明已经有可读取正文，仍缺正式内容定稿的关闭记录。自动读取云账单尚未实现，但未找到它是本轮已确认必做范围的依据，单列 C，不扩大为必须开发。
5. 清理了 4 个确认无容器、无已登记恢复引用、无子镜像依赖的旧 STL 镜像记录。所有 56 个容器的身份、镜像、运行状态、启动时间和挂载保持不变。Docker 汇总镜像空间仍为 92.53GB，**不能宣称释放了这些镜像标称大小之和**。

## 本轮补回的缺口和待确认事项

### O12 / AUTH-OAUTH-01，A，第三方登录未实现

- **证据**：`web/components/auth-form.tsx:113` 的 Apple/Google 按钮硬编码 `disabled`；`api/accounts/urls.py` 没有 OAuth 登录/回调路由。`AUTH_ENTRY_20261023.md` 已明确记录 PDF 186–190 的第三方控件没有现成后端。本轮实际 `/login` 仍显示“第三方登录暂未开放”。
- **触发与影响**：读者选择页面上提供的 Apple 或 Google 登录，不能开始认证。书库原有密码登录不受此项影响。
- **最小范围**：若保持 PDF 入口，补对应认证、回调、账号关联及必要的客户端配置；沿用现有 User/权限，不创建第二套账户。不能只去掉 `disabled` 或仅填一个密钥。
- **需要明确的最终形态**：默认依据 PDF 保留两种入口。若用户决定上线只用书库账号，应明确撤销这两种入口的范围，再处理展示。凭据由持有人安全配置，不在聊天索取。
- **记录纠正**：旧收尾记录把 OAuth 泛归为“未确认的新需求/只有配置”，证据不足。本项是原已知缺口没有在后续清单正确跟踪，不是本轮新发明的功能。

### O13 / AI-RUNTIME-01，A 环境，平台生成式模型未接通

- **调用和实际影响**：

|---|---|---|
| `api/reading/local_analysis.py::generate_local / analyze_local_relations` | 在报告或反证中明确选原文后请求关系分析 | 配置禁用，返回分析不可用/待核实；规则线索和原文保留 |
| `api/reading/research_comparison.py::process_draft` 调用 `generate_local` | 请求私人比较草稿 | 没有平台模型可生成草稿；并非选材/证据矩阵整个模块不存在 |
| `api/reading/local_analysis.py::propose_plan_labels` | 请求计划阶段、学习目标和理由补充 | 保留规则生成顺序，不得到模型补充；不能说所有阅读计划都不可用 |

- **最小范围**：明确并配置现有能力适配器要使用的本地生成服务和模型，再做对应操作验收；不替换用户已选检索模型、不外发私人材料、不重新开发能力框架。恢复 worker 不能独自解决配置缺失。

### O14，B，正式条款和隐私正文定稿

`/help/terms` 和 `/help/account` 均为 200，有现有公开正文、无“尚未发布”或读取失败提示。`web/app/help/[slug]/page.tsx` 从网站内容取 `about-open/about-copyright/about-notice/about-privacy`；注册页链接到这些正文。本项不是缺页面或缺发布接口，而是旧 AUTH_ENTRY 中的正式内容定稿未有关闭记录。需要用户/运营者核对最终文字；本轮不修改政策文字，不作法律合规结论。

### O15，C，自动云账单是否属于产品范围
