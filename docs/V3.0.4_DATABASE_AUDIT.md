# 3.0.4 生产数据库核对

核对时间为 2026-09-05 13:17，香港时间。生产仍为 3.0.3，本报告不表示 3.0.4 已迁移或上线。

## 核对范围和方式

通过当前生产 API 容器读取同一 PostgreSQL 16.14 数据库。事务明确设置 READ ONLY。盘点 catalog、ingestion、reading、distribution 的各模型数量及迁移，检查核心对象身份、规范化同名、贡献者重复、当前文件唯一性、公开资格和正式人物关系。随后只读扫描真实 Meilisearch passages 与唯一活动语义索引，逐条核对其 edition_id 和 is_public。

完整报告仅存放被 Git 忽略的本地部署记录，不提交数据库、用户私人内容或凭据。报告包含标识符用于升级前后比对，不据此执行自动合并。

## 确认存在的不一致

1. 《社会学的基本概念》已发布，但没有 approved 作者关系。现有马克斯·韦伯、顾忠华两条关系均为未确认 author，来源为 entity_resolution_unresolved。不得把这些机器关系直接提升，特别是不能仅凭姓名猜测译者角色。旧语义状态为 failed，正文质量记录为 0，实际全文和语义索引均无该书正文。PDF 仍应正常开放，作者字段提示待确认。
2. 《质的研究方法与社会科学研究》仍是草稿。陈向明的作者关系已经 approved，source 为 workflow_section_confirmation，但 Person 仍是 draft。这是有效的草稿关联，不是作者缺失。升级需要为这一类明确人工确认的旧关联建立编目发布包，保存草稿保持不公开，正式发布时再一起提升。
3. 存在一条未关联当前贡献者的草稿人物记录，姓名混合多人及网站标识。保留并标为人工核查对象，不批量删除。另有空题名草稿、出版社字符串带字段前缀等草稿质量问题，需要在对应字段处理。
4. 《弱者的武器》旧正文质量低于新质量门槛，全文旧索引中有 46 条公开文档。3.0.4 应按活动修订和质量资格排除其正文语义材料，不能据旧 indexed 状态认定正文合格。原 PDF 不受影响。
5. 部分作品的 OCR pending/running 与目前没有运行 OCR 任务并不一致。存在 6 个用户暂停的 OCR 任务，升级不能擅自恢复。正文是否可用须依据真实 DocumentRevision 与质量评估，不能只看旧 OCR 状态标签。
6. 一批历史 MetadataCandidate 标记 accepted，却没有 accepted_by/accepted_at。其中部分值与当前人工馆藏不同。这些记录不能被迁移成正式事实，更不能回写覆盖现有元数据。新只读审计将列出差异及证据不足。

## 实际派生数据

全文 passages 实际 3,604 条，其中 748 条草稿材料仍是 private。唯一活动语义索引为 semantic_passages_20260818210650_4cf87bc9，实际 3,005 条。两个索引中草稿且 is_public=true 的数量都为 0，未发现这类草稿泄漏。

QueryLexicon 需要按 3.0.4 的正式来源 registry 重建，不能仅因旧条目 public_active 就视为来源已确认。旧活动词典及全部索引保留回退入口，不在审计过程中清空。

## 对齐规则和发布门槛

- Schema 仅通过 Django 0040、0041 迁移。先在新备份恢复的隔离 PostgreSQL 16 中执行，再检查原对象 ID、原始 PDF 摘要和页码身份保持不变。
- 已发布馆藏初始化活动快照，兼容原已确认作者和真实阅读文件。未确认人物保持待审核。
- 历史草稿发布包只回填有明确人工确认依据的实体关系。候选 accepted 不构成依据。
- 搜索只添加修订过滤字段，不清除文档、不重新配置 embedding 模型。现有活动版本保留。
- 歧义人物、角色、别名、理论映射以及候选与正式字段冲突只生成审核事项。派生词典和索引的确定性修复由受控发布服务执行。
- 新全库审计命令支持 --database-read-only 和 --schema-only。未对齐 schema 时必须明确停止详细数据检查，不能误报健康。
